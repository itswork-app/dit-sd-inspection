# Dit. SD Inspection

Replacement application for the existing inspection workflow used by Direktorat Sekolah Dasar (Dit. SD).

## Product scope
Initial release covers two inspection instruments only: Interactive Flat Panel (IFP) and Standing Bracket.

Delivery strategy: feature parity first, controlled improvements second. The legacy application is a workflow/output reference only. This is a greenfield project; no legacy source-code or database access is assumed.

## Delivery target
- Release target: Production
- Engineering priority: Balanced (quality, security, cost, and delivery speed)
- Delivery model: gated phases with documented acceptance criteria and evidence.

## Project status
Phase 0 — Project Foundation. Product specification, architecture, implementation, and production readiness are not yet declared complete.

See docs/00-project-charter for the project charter, governance, and Phase 0 plan.
